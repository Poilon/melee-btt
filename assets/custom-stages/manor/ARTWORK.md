# Painted manor artwork

Created for TTRC with the built-in imagegen tool, using the authored manor mesh
preview as the spatial reference. This is a static painted backdrop; native
targets, characters, collisions and camera remain separate game objects.

The PNG is the editable source asset. Four scene CMPR files, a ledge sprite and scene.json are
runtime assets generated by scripts/encode_stage_art.py (Pillow + NumPy).
Portable builds consume those files without an image-library dependency.
